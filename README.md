# Мини-синхронизатор заявок

Cloudflare Worker получает свежий список с `https://test.ooobs.ru/api/orders` при каждом GET-запросе, приводит телефоны к виду `+7XXXXXXXXXX`, отбрасывает невалидные номера и оставляет для каждого телефона запись с максимальной суммой. При равной сумме выбирается более поздняя заявка. Результат не хранится между вызовами, поэтому повторный запрос идемпотентен.

Секретов и ключей в проекте нет: источник доступен публично, состояние не хранится. Развертывание: `npm install`, затем `npm run deploy`.

Эндпоинт Worker возвращает JSON по заданной схеме на любом GET-пути.
